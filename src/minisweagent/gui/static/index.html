Runs use the local shell instead of Docker (). environment_class, image and cwd are replaced by the workspace; everything else (timeout, env vars, clean_start, …) is used.

Test reproduction (config: reproduction). When enabled, each request first runs a reproducer agent in a scratch clone of your repository: it writes tests plus a run_test.sh that must show a FAILED test on the current code. The tree search then runs them at the root and after every code edit, and uses the outcome to shape the rewards (needs agent.shape_reward). The tests never become part of the result. It uses the policy model and adds one agent run per request.
